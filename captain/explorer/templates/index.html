Core Research Foundations & Problem Statement

Why investigating agent failure propagation requires intervening at the channel granularity.

⛓

The Cascading Failure Problem

In autonomous multimodal agent workflows, a subtle tool error or corrupted artifact early in the trace propagates downstream through reasoning steps, triggering catastrophic task failure.

✂

The Coarse Granularity Bottleneck

Existing debugging systems intervene at the source-event or full-step level. When a step produces multiple outputs, rewriting the entire step alters unrelated valid evidence (collateral damage).

🎯

The CELA Contribution

CELA intervenes at the individual evidence-flow channel level via artifact substitution, fixing the localized causal failure path while keeping unrelated evidence strictly invariant.

📐

Counterfactual Evidence-Flow Effect

CEE formalizes do-calculus interventions on evidence channels: measuring how failure probability drops when intervening on channel $E_{i \to j}$ without disturbing orthogonal dependencies.

Act I: The Fragility of Agent Chains

Autonomous agents break down complex tasks into sequential tool invocations and memory updates. A single poisoned observation creates a silent error cascade.

Act II: The Failure of Step-Level Debugging

When an agent fails, current methods point to the entire step. In shared-source architectures, this coarse diagnosis causes collateral damage by altering correct parallel outputs.

Act III: Channel-Level Attribution

CELA isolates the precise evidence channel carrying the failure, substituting only the faulty artifact and evaluating counterfactual replay.

The Research Question: When multi-step LLM agents fail, how can we attribute failure to specific evidence-flow channels rather than entire tool steps, and how can we repair execution with zero collateral damage to valid co-produced evidence?
THE PROBLEM

The Agent Failure Crisis & The Granularity Bottleneck

Multi-step LLM agents fail in cascading chains, but existing debuggers only inspect steps.

The Coarse Step-Level Bottleneck

Existing agent evaluation treats tool executions as monolithic black boxes. If tool Step #2 produces two outputs—one containing a flawed currency exchange rate and another containing an audited tax bracket—step-level debugging discards or reruns the entire step.

The CELA Solution: Channel-Level Lineage

CELA decomposes agent execution into a formal bipartite provenance DAG, tracking individual evidence channels. By substituting only the faulty artifact and holding parallel co-produced artifacts invariant, CELA repairs failures without collateral damage.

FOUNDATIONAL ARCHITECTURE

CAPTAIN: Bipartite Execution Provenance DAG

Strict mathematical separation between computational Events and typed Artifacts.

\[ G = (V_E \cup V_A, \; E_{\text{prod}} \cup E_{\text{cons}}), \quad E_{\text{prod}} \subseteq V_E \times V_A, \quad E_{\text{cons}} \subseteq V_A \times V_E \]
1. Events ($V_E$)

Discrete agent actions, tool dispatches, LLM completions, and sensor updates with deterministic sequence numbers.

2. Artifacts ($V_A$)

Immutable data payloads with canonical JSON SHA-256 content hashes to detect mutation or corruption across steps.

3. Bipartite Invariant

Direct Event-to-Event edges are forbidden; all causal transmission must occur via explicit evidence artifacts.

ALGORITHMIC PIPELINE

The CELA 4-Stage Counterfactual Pipeline

From graph reachability to Pareto-optimal knapsack intervention.

STAGE 1 (A1 ≡ B2)
Provenance Slicing

Backwards reachability from failure symptom in bipartite graph G.

STAGE 2 (A2 ≡ B3)
CEE Replay Screening

Single-channel counterfactual replays; filters channels with CEE < threshold.

STAGE 3 (A3)
Cascade Lookahead

Evaluates multi-hop downstream state mutations; suppresses distractors.

STAGE 4 (A4/A5)
Pareto Optimization

Multi-objective knapsack maximizing utility: U = CEE - λ · Cost.

SCIENTIFIC HONESTY

Negative Results & Limitations: Claim C3 (p = 0.1156)

Transparent reporting of negative findings and environmental caveats.

⚖️

Claim C3 is Formally NOT SUPPORTED on Causal F1

Permutation testing reveals that CELA A5 (F1 = 0.6788) does not statistically outperform Random Baseline B1 (F1 = 0.8152) on raw F1 alone ($p = 0.1156$).

The Explanation: On small synthetic DAGs with few candidates, random sampling frequently strikes the causal channel by chance without set-size penalty. The true contribution of CELA is not raw F1 in trivial graphs, but 100% distractor rejection and 64.8% cost savings in multi-path cascades.

* Determinism Caveat: Convergence results (CEE=1.0, CI width=0.0) are facilitated by deterministic MockLLM replay semantics. Real LLMs introduce stochastic token variance.
